# Current component catalog

Storybook renders current controlled production components with app CSS. It is not an alternate application, design-history archive, or API client. Authentication and network lifecycles are exercised separately through production-container integration tests and native browser tests.

- `Workspace/Statistics` is canonical: `AnalyticsStory` is a story-local date harness around real `ManagementFrame` and `Analytics` → `StatisticsOverview`. Overview, empty, loading and failed are distinct states. Daily activity is clicks-only; summary cards retain bot and preview totals; all three all-event rankings stay visible.
- `Workspace/Editor` is the single canonical editor catalog. It renders the real LinkEditor, with the actual ManagementFrame for existing-link pages, including long read-only addresses and save failure. Create-link states retain editable custom aliases. Route authority and navigation remain covered separately by native management tests.
- Administration renders the actual shared AdminPanel consumed by the independent admin application; its sign-in coverage is separate from user access. User sign-in, account/passkey, dashboard, transient toast (copy and quick-action notices), import, form/error and native public-template states remain covered by their current components.

Statistics fixtures are deterministic illustrative observations, not production captures. The finite event set spans 2026-10-18 through 2026-11-14. Every event has a day and category identities; all period totals and category counts are derived by filtering those events. Bot and preview fixtures occur on the final fixture day and are never displayed as invented daily series. Arbitrary date ranges filter this finite set, including honest empty ranges. Fixed loading/error states do not pretend to complete API requests. The real ManagementContainer owns current UTC presets and actual unrestricted API ranges, observed response ownership, retry and navigation.

Browser verification: build Storybook into a candidate directory, serve it locally, then run `node scripts/verify-current-storybook.mjs` with `STATISTICS_PREVIEW_URL` and `EVIDENCE_DIR` as needed. The verifier checks the index contains no obsolete design/comparison/playground entries, then exercises the canonical real overview, states, exact hover/tap detail, draft/apply/preset dates, native date editor segments and 1440/390/320 geometry in light/dark, with zero API calls.

Removed preview-only behavior is not a product contract. Its editor/cancel/search/copy cases are represented by current controlled-component and AppContainer integration tests rather than another fake CRUD shell. Preserve legal notices and licenses independently of the component catalog.
